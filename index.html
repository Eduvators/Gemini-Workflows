Overview

Use AI in ways that are practical, grounded, and useful

This workshop site is built to be more teachable. Instead of a time based agenda, it is organized around the actual work faculty want to do: create something useful, keep it grounded in trusted materials, and improve work inside Google tools.

✦

Create

Use Gemini to brainstorm, draft, revise, explain, and generate practical teaching or communication materials.

📚

Ground

Use NotebookLM to turn course materials, policies, standards, and program documents into source grounded resources.

⚙

Improve

Use Gemini in Google Workspace to improve writing, presentations, email, organization, and planning where the work already happens.

Best practice: start with verified information, choose the right AI tool, and keep the final decision in human hands.

Tool Guide

When to use each Google AI tool

Gemini

Create and refine

Best for brainstorming, drafting, rewriting, activity design, visual concepts, explanations, and repeatable assistants such as Gems.

Faculty example: turn a verified program brief into an orientation message, FAQ, social caption, or lesson activity.

NotebookLM

Ground in trusted sources

Best for source based work using syllabi, standards, manuals, handbooks, policies, and approved program documents.

Faculty example: create a study guide, course overview, comparison, or review questions that stay close to the source set.

Workspace

Improve work in context

Best for tasks inside Docs, Slides, Sheets, Gmail, Drive, Forms, or Vids when available in the participant account.

Faculty example: revise an existing orientation page, summarize themes in a sheet, or draft a polished email reminder.

Gemini live prompt

Create a short orientation message for [AUDIENCE] entering [PROGRAM]. Use only the facts below. Keep it welcoming, practical, and under 180 words. Preserve all dates and requirements exactly. Mark missing information [CONFIRM]. Finish with a short accessibility review. Facts: [PASTE VERIFIED BRIEF].

NotebookLM live prompt

Using only the selected sources, create a one page study guide for [TOPIC]. Include 8 key ideas, 6 vocabulary terms, 5 practice questions, and a short section called “What learners often confuse.” Cite the supporting source for each major section.
Tip: if a feature is not available in one participant account, focus on the workflow concept rather than the exact interface.

Hands On Practice

Choose one challenge

These are simple, visible, and ready to facilitate. Each one includes an expected human decision.

1

Gemini content sprint

Create an orientation message, FAQ, social caption, or classroom activity from a verified program brief.

Human decision: improve accuracy, tone, accessibility, or usefulness.

2

NotebookLM grounded resource

Create a study guide, FAQ, comparison, or review quiz from one to three trusted sources.

Human decision: open at least one citation and verify the result.

3

Workspace improvement

Use Gemini in Docs, Slides, Sheets, or Gmail to improve something you already do.

Human decision: compare the AI version with the original and keep only what is better.

Prompt Playbook

Prompts to use right away

Rewrite for a new audience

Rewrite this text for [AUDIENCE]. Keep every date, requirement, link, and credential statement unchanged. Use shorter sentences and clear headings. Text: [PASTE].

Explain a topic simply

Explain [TOPIC] to a beginning learner in plain language. Use one short analogy and three key points. Avoid jargon unless you define it.

Design a short learning activity

Design a 20 minute learning activity for [TOPIC]. Audience: [LEARNERS]. Learning outcome: [OUTCOME]. Available materials: [MATERIALS]. Include instructions, check for understanding, accessibility options, and a 3 question reflection.

Draft a student communication

Draft a message to [AUDIENCE] about [PURPOSE]. Tone: warm and professional. Use only the verified information below. Put the most important action first. Keep it under 180 words. Verified information: [PASTE].

Create a reusable Gem

Create instructions for a reusable faculty assistant that helps with [TASK]. It must use only instructor supplied or attached sources, preserve verified details, avoid invented requirements, use accessible plain language, and flag uncertainty with [CONFIRM]. Add a final human review checklist.

Plan a multi tool workflow

Help me plan a workflow using Gemini, NotebookLM, and Google Workspace for [TASK]. For each step, state the purpose, the best tool, the source material needed, the human review decision, and the final deliverable.

Responsible AI

Review before you share

AI can speed up the work, but faculty expertise remains essential.

  • Accuracy: verify names, dates, requirements, credentials, safety information, and technical claims.
  • Grounding: trace important claims to an approved source.
  • Privacy: avoid confidential or personally identifiable student information unless explicitly allowed by policy.
  • Bias: review for stereotypes, exclusions, and unsupported assumptions.
  • Accessibility: use headings, readable structure, descriptive links, plain language when appropriate, and meaningful alt text.
  • Human oversight: keep an appropriate person responsible for the final decision.
  • Transparency: be able to explain how AI contributed when the context calls for it.
