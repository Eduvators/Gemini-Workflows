# Tri Cities ROP Workshop 2 Website

Single page workshop website for:

**Google AI for Educators: Gemini, NotebookLM & the Workspace Toolkit**

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload `index.html` to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save. GitHub will provide the public site URL.

No build process or external dependencies are required.
